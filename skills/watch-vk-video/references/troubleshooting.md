# Если рядом со скиллом нет `scripts/vk_fetch.py`

Это не поломка плагина, а не та площадка. В облачную песочницу (обычный чат
claude.ai и Claude Desktop) копируется только каталог скилла, а сети до ВК оттуда
нет вовсе — `vkvideo.ru` отдаёт `403 host_not_allowed`. Ставить yt-dlp и искать
обходы бессмысленно: скачивать всё равно неоткуда.

Скажи это человеку и предложи Claude Code, Cowork или MCP-сервер плагина
(`analyze_vk_video`). Содержание ролика не выдумывай.

# Что делать при `"ok": false`

Скрипт всегда возвращает `error_code`. Найди свой, объясни человеку своими словами
и предложи конкретную команду. Не показывай стектрейсы и не пробуй обойти запрет.

## `no_ffmpeg`

Нет `ffmpeg` в PATH — без него не получить ни звук, ни кадры. Дай команду под ОС
пользователя и попроси открыть новый терминал (PATH подхватывается не сразу):

- Windows: `winget install Gyan.FFmpeg` (или `choco install ffmpeg`)
- macOS: `brew install ffmpeg`
- Linux: `sudo apt install ffmpeg` / `sudo dnf install ffmpeg`

## `no_ytdlp`

Не установлен `yt-dlp`: `pip install -U yt-dlp`. Если pip ставит в другой Python,
чем тот, которым ты запускаешь скрипт, помогает `python -m pip install -U yt-dlp`.

## `extractor_broken`

ВК поменял отдачу видео, yt-dlp за этим не успел. Это не поломка плагина, а
нормальный режим работы: так было, например, в феврале 2026 с ошибкой
`Unable to extract player params`.

1. `pip install -U yt-dlp` — в девяти случаях из десяти чинит.
2. Не помогло — баг ещё не исправлен: https://github.com/yt-dlp/yt-dlp/issues?q=is%3Aissue+vk
   Скажи об этом прямо, предложи вернуться через несколько дней. Не пытайся
   выкачать видео другими способами.

## `auth_required`

Видео приватное, 18+, в закрытом сообществе или заблокировано в регионе.
Единственный рабочий путь — куки браузера, где человек залогинен в ВК:

```bash
python "<каталог скилла>/scripts/vk_fetch.py" "<URL>" --cookies-from-browser chrome
```

Вместо `chrome` бывает `firefox`, `edge`, `opera`, `brave`, `vivaldi`, `chromium`.
Браузер при этом лучше закрыть — иначе он держит базу кук заблокированной.
Если у человека нет доступа к видео и в браузере — доступа не будет и у нас,
предлагать обходы блокировки не нужно.

## `bad_url`

Ссылка не распознана. Поддерживаются `vkvideo.ru`, `vk.com`, `vk.ru`: страница
видео, клип, embed-плеер (`video_ext.php`), ссылка из плейлиста и со стены.
Ссылка на канал (`vk.com/video/@name`) или на плейлист целиком — не видео,
попроси конкретный ролик. Прямые эфиры не поддерживаются.

## `unknown`

Всё остальное: сеть, диск, оборванное скачивание. В `message` лежат первые строки
исходной ошибки — покажи их коротко и предложи повторить запуск (кэш не даст
качать заново то, что уже скачалось).

# Не ошибка, но стоит сказать

- `warnings: ["faster-whisper не установлен…"]` — транскрипта нет, работаешь только
  по кадрам. Поставить: `pip install faster-whisper`. Скажи об этом один раз, не ной.
- `transcript_path: null` при пустых warnings — whisper отработал, но текста нет:
  скорее всего в ролике нет речи.
- Всё пусто, а кадров мало — проверь `duration`: у прямых эфиров и заглушек его нет.
